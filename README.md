# Dog Query App

This project uses React, Vite, and TanStack Query to fetch data from the Dog API.

## Features

- Fetches dog breeds
- Shows loading, error, and success states
- Displays detailed breed information
- Shows random dog facts
- Shows dog groups

## How to Run

```bash
npm install
npm install @tanstack/react-query
npm run dev
